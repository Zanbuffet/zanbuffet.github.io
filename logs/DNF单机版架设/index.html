    随后安装vm tool，但是因为Win7无法直接安装vmtool，会提示“Windows无法验证此驱动程序软件的发布者”，由于微软更新了驱动程序签名算法，2019年开始弃用SHA1，改用SHA2。猜测VMware Tools驱动程序使用SHA2，而Windows7只支持SHA1，需要下载安装补丁kb4474419来支持SHA2算法。
    Microsoft Update Catalog
    2019-适用于 Windows 7 的 09 安全更新，适合基于 x64 的系统(KB4474419)| 这个补丁。

    随后，需要将该补丁送进win7虚拟机当中，我的方法是
    把Win7虚拟机的联网方式改为桥接（设置-网络适配器-网络链接-桥接模式）
    然后在主机里的“查看网络计算机和设备”中找到Win7虚拟机，网络凭证输入Win7虚拟机的开机登录账号和密码。

    以上方法不能稳定复现，采用下面的方法：

    虚拟机设置改为NAT模式，然后进入客机的“网络”中打开分享，然后回到“我的电脑“中上侧菜单栏”映射网络驱动器“，将Users添加进去，然后再主机中的地址栏输入”\客机的计算机名“，例如客机名字叫”John-PC“,就输入"\John-PC"，就能够直接操作文件夹了。
    注意，Win7虚拟机的登录密码不能为空，否则即使登陆账号正确，密码留空，也无法通过网络凭证认证。需要在Win7虚拟机里设置一下开机密码，即可通过网络凭证认证。
    然后把补丁扔进Win7虚拟机里，再安装VM Tool即可。

    [hell freepass item]
    8272 1

    [item condition]
    3330
    [/item condition]
